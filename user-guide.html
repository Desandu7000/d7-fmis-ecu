User guide

Step-by-step help for each task in the FMIS.

Log a maintenance call

Open Maintenance Call → Log a maintenance call, choose the call type and room, add any notes and select Log call. The call starts in the Logged state. You can cancel it from My maintenance calls while it is still Logged.

Request or change an office move

Open Move Management → Request a move and give the origin room, destination room and preferred date. You can change or cancel the request from Cancel or edit move up to 24 hours before the move date.

Add or update a furniture asset (FMO)

Open Furniture Assets → Add furniture asset, enter the barcode, description, cost, supplier and room, then Save. Use Update furniture asset to edit a record, mark it beyond repair or sold, or print its label.

Generate the FMO Asset Report (FMO)

Open FMO staff → Generate FMO report, choose a building and floor, and the report shows the occupant, space details and furniture for each room, with room totals and floor totals.
